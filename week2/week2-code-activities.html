⚡ Part A — Recursion Quick Quiz

Question 1

What is the output of factorial(0) given the typical recursive definition?

  • 0
  • 1
  • Infinite recursion
  • Undefined
By convention 0! = 1. The base case handles n ≤ 1 and returns 1, so factorial(0) = 1.
Question 2

How many permutations does the string "ABCD" (4 unique chars) have?

  • 8
  • 16
  • 24
  • 48
4! = 4×3×2×1 = 24. General rule: n distinct characters → n! permutations.
Question 3

How many subsets does the set {1, 2, 3, 4} have?

  • 8
  • 12
  • 15
  • 16
2⁴ = 16. Each element has 2 choices (in/out), so for n elements there are 2ⁿ subsets (including the empty set).
Question 4

What is the space complexity of a recursive function with n recursive calls and no extra data structures?

  • O(1)
  • O(n) — call stack depth
  • O(n²)
  • O(log n)
Each recursive call adds a frame to the call stack. With n calls in a linear chain, the maximum stack depth is n → O(n) space.
Question 5

In the backtracking template, what is the purpose of the "UNCHOOSE" step?

  • Restore state so the next sibling branch starts from a clean state
  • Terminate the recursion early
  • Save memory by deleting the result
  • Skip invalid branches
After exploring one path, we must undo the last decision (pop from current, re-add to remaining) so the parent loop can try the next option with an unmodified state. Without unchoose, state leaks across siblings.

Backtracking O(n·2ⁿ)

#46 · Permutations

Medium

Given an array of distinct integers, return all possible permutations in any order.

Backtracking O(n·n!)

Pass a used boolean array instead of slicing. At each level, try every unused element, mark it used, recurse, unmark (backtrack).

#39 · Combination Sum

Medium

Given an array of distinct candidate integers and a target, return all unique combinations that sum to target. The same number may be used multiple times.

Backtracking Pruning

Sort candidates first. In the recursive loop, start from the same index (not i+1) to allow reuse. Prune by checking if remaining < 0 after subtracting.

Easy

Reverse a singly linked list. Solve it both iteratively and recursively, then compare the space complexity of each approach.

Recursion O(n) space recursive O(1) space iterative

✏️ Part C — Trace Exercise (In-class)

Manually trace the call tree for the code below with input ['X','Y']. Draw each recursive call, the state of current at each node, and circle the base-case nodes. Compare your drawing with a partner.

def backtrack(current, remaining):
    if not remaining:
        print(current)
        return
    for i in range(len(remaining)):
        current.append(remaining[i])
        backtrack(current, remaining[:i] + remaining[i+1:])
        current.pop()

backtrack([], ['X', 'Y'])

Expected output: ['X','Y'] then ['Y','X']. How many total function calls happened?

🤝 Part D — Peer Review Checklist

  • Base case present: Is there a base case that stops the recursion?
  • Backtrack step: Does the code explicitly undo the "choose" step (e.g., current.pop())?
  • No mutation leaks: Is a copy (list(current)) appended to results, not a reference?
  • Complexity stated: Are both time and space complexity correctly identified?
  • Edge cases tested: Empty input, single element, duplicates (if applicable)?
  • One improvement suggestion written by the reviewer.
