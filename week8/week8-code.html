Heaps & Priority Queues

Min-Heap · Max-Heap · K-th Largest · Merge K Sorted · Top K Elements

🎯 Learning Objectives

  • Apply the "min-heap of size k" pattern to solve k-th largest and top-k problems in O(n log k).

🏔️ 1 · Heap Fundamentals

A min-heap is a complete binary tree where every parent is ≤ both children. This guarantees the minimum element is always at the root, giving O(1) min access and O(log n) push/pop.

Python heapq — always a min-heap

Pythonimport heapq

h = []
heapq.heappush(h, 5)
heapq.heappush(h, 1)
heapq.heappush(h, 3)

print(heapq.heappop(h))   # 1 — always pops the minimum
print(h[0])               # peek at min without popping

# Max-heap: negate all values
max_h = []
for v in [5, 1, 3]:
    heapq.heappush(max_h, -v)

print(-heapq.heappop(max_h))  # 5 — largest element

# Build heap in O(n) from a list
nums = [3, 1, 4, 1, 5]
heapq.heapify(nums)

🎯 2 · Pattern: K-th Largest Element

LeetCode #215. Find the k-th largest element in an unsorted array.

Key insight: Maintain a min-heap of size exactly k. After processing all elements, the root (minimum of the heap) is the k-th largest overall — everything in the heap is bigger than the rest of the array. 
Pythonimport heapq

def findKthLargest(nums: list[int], k: int) -> int:
    # Min-heap of size k — root is the k-th largest so far
    min_h = nums[:k]
    heapq.heapify(min_h)              # O(k)

    for n in nums[k:]:
        if n > min_h[0]:              # larger than current k-th
            heapq.heapreplace(min_h, n) # pop min, push n — O(log k)

    return min_h[0]                   # O(n log k) total
Complexity: O(n log k) time — far better than O(n log n) sort when k ≪ n. O(k) space.

🔗 3 · Pattern: Merge K Sorted Lists

LeetCode #23. Given k sorted linked lists, merge them into one sorted list. Brute force: collect all values, sort, rebuild — O(N log N). Heap approach: O(N log k).

Pythonimport heapq

class ListNode:
    def __init__(self, val=0, next=None):
        self.val, self.next = val, next

def mergeKLists(lists: list[ListNode]) -> ListNode:
    dummy = ListNode()
    curr  = dummy
    heap  = []                         # (value, index, node)

    for i, node in enumerate(lists):
        if node:
            heapq.heappush(heap, (node.val, i, node))

    while heap:
        val, i, node = heapq.heappop(heap)
        curr.next = node
        curr = curr.next
        if node.next:
            heapq.heappush(heap, (node.next.val, i, node.next))

    return dummy.next                  # O(N log k), N = total nodes
Python gotcha: When two nodes have the same value, Python tries to compare the second tuple element (the ListNode) — this causes a TypeError. Always include a tiebreaker index i as shown above.

📊 4 · Pattern: Top K Frequent Elements

LeetCode #347. Given a list of integers, return the k most frequent elements.

Pythonfrom collections import Counter
import heapq

def topKFrequent(nums: list[int], k: int) -> list[int]:
    count = Counter(nums)              # {value: frequency}
    # nlargest: O(n log k) using an internal heap
    return heapq.nlargest(k, count.keys(), key=lambda x: count[x])
Alternative — bucket sort: Create an array of size n+1 where index = frequency. Iterate from high to low frequency. O(n) time, O(n) space.

📍 5 · Pattern: K Closest Points to Origin

LeetCode #973. Find the k closest points to (0,0) by Euclidean distance.

Pythonimport heapq

def kClosest(points: list[list[int]], k: int) -> list[list[int]]:
    # Max-heap of size k: pop when a closer point is found
    heap = []
    for x, y in points:
        dist = x**2 + y**2               # no need for sqrt
        heapq.heappush(heap, (-dist, x, y))  # negate = max-heap
        if len(heap) > k:
            heapq.heappop(heap)          # remove farthest of the k+1
    return [[x, y] for _, x, y in heap]  # O(n log k)

📋 6 · When to Use a Heap

Problem patternData structureComplexity
Find k-th largest / smallestMin/Max-heap of size kO(n log k)
Top k frequentHeap + CounterO(n log k)
Merge k sorted streamsMin-heap of size kO(N log k)
Sliding window maximumDeque (monotonic)O(n)
Median from data streamTwo heaps (min + max)O(log n) per insert
Dijkstra's shortest pathMin-heapO((V + E) log V)
Rule of thumb: Reach for a heap when the problem says "k largest", "k smallest", "streaming top-k", or "merge multiple sorted sources". The word k is the hint — the heap size is k, so complexity is O(n log k).
