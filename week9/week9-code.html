🗺️ 1 · Graph Fundamentals

A graph G = (V, E) consists of vertices V and edges E. Almost every real-world network — social connections, road maps, package dependencies, web links — is a graph.

Graph Taxonomy

Representations

Adjacency List (preferred for sparse graphs): O(V+E) space, O(degree) to find neighbours.

Adjacency Matrix: O(V²) space, O(1) edge lookup. Use only for dense graphs or when O(1) edge queries matter.

Pythonfrom collections import defaultdict

# Build adjacency list from edge list
def build_graph(n: int, edges: list[list[int]], directed=False) -> dict:
    graph = defaultdict(list)
    for u, v in edges:
        graph[u].append(v)
        if not directed:
            graph[v].append(u)
    return graph

# Example: 4 nodes, edges 0-1, 0-2, 1-3, 2-3
g = build_graph(4, [[0,1],[0,2],[1,3],[2,3]])
# g = {0:[1,2], 1:[0,3], 2:[0,3], 3:[1,2]}

🔍 2 · DFS — Depth-First Search

DFS explores as far as possible along each branch before backtracking. Time: O(V+E). Use for: connected components, cycle detection, topological sort, path existence.

Recursive Template

Pythondef dfs_recursive(graph: dict, node: int, visited: set) -> None:
    visited.add(node)
    for neighbour in graph[node]:
        if neighbour not in visited:
            dfs_recursive(graph, neighbour, visited)

# Count connected components
def count_components(n: int, graph: dict) -> int:
    visited = set()
    count = 0
    for node in range(n):
        if node not in visited:
            dfs_recursive(graph, node, visited)
            count += 1
    return count

Iterative DFS (avoids recursion limit)

Pythondef dfs_iterative(graph: dict, start: int) -> list[int]:
    visited = set()
    stack = [start]
    order = []
    while stack:
        node = stack.pop()
        if node in visited:
            continue
        visited.add(node)
        order.append(node)
        for neighbour in graph[node]:   # push in reverse for left-to-right order
            if neighbour not in visited:
                stack.append(neighbour)
    return order

🔄 3 · BFS — Breadth-First Search

BFS explores all neighbours at distance k before visiting nodes at distance k+1. It guarantees the shortest path in unweighted graphs. Time: O(V+E).

Pythonfrom collections import deque

def bfs(graph: dict, start: int) -> list[int]:
    visited = {start}
    queue = deque([start])
    order = []
    while queue:
        node = queue.popleft()
        order.append(node)
        for neighbour in graph[node]:
            if neighbour not in visited:
                visited.add(neighbour)
                queue.append(neighbour)
    return order

def shortest_path(graph: dict, start: int, end: int) -> int:
    """Returns hop count of shortest path, or -1 if unreachable."""
    visited = {start}
    queue = deque([(start, 0)])
    while queue:
        node, dist = queue.popleft()
        if node == end:
            return dist
        for neighbour in graph[node]:
            if neighbour not in visited:
                visited.add(neighbour)
                queue.append((neighbour, dist + 1))
    return -1
BFS vs DFS — Decision Guide
Use BFS when: shortest path (unweighted), level-order traversal, "minimum steps" problems.
Use DFS when: connectivity, cycle detection, topological sort, exhaustive path exploration.

🔁 4 · Cycle Detection

Undirected Graph — Parent Tracking

An undirected graph has a cycle if DFS finds a visited neighbour that is NOT the node we came from.

Directed Graph — Color States

Use three states: WHITE (unvisited), GRAY (in current DFS path), BLACK (fully explored). A back-edge to a GRAY node = cycle.

Pythondef has_cycle_directed(n: int, graph: dict) -> bool:
    # 0=white, 1=gray (in stack), 2=black (done)
    color = [0] * n

    def dfs(node: int) -> bool:
        color[node] = 1                        # mark gray
        for neighbour in graph[node]:
            if color[neighbour] == 1:          # back-edge → cycle
                return True
            if color[neighbour] == 0 and dfs(neighbour):
                return True
        color[node] = 2                        # mark black
        return False

    for node in range(n):
        if color[node] == 0 and dfs(node):
            return True
    return False

🏝️ 5 · Connected Components — Count Islands

LeetCode #200 "Number of Islands" is the canonical connected-components problem: a 2D grid treated as a graph where adjacent '1' cells are connected.

Pythondef numIslands(grid: list[list[str]]) -> int:
    if not grid:
        return 0
    rows, cols = len(grid), len(grid[0])
    count = 0

    def dfs(r: int, c: int) -> None:
        if r not in range(rows) or c not in range(cols) or grid[r][c] != '1':
            return
        grid[r][c] = '0'                    # mark visited by sinking
        dfs(r+1,c); dfs(r-1,c); dfs(r,c+1); dfs(r,c-1)

    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == '1':
                dfs(r, c)
                count += 1
    return count

# Time: O(rows × cols), Space: O(rows × cols) call stack

📋 6 · Topological Sort

A topological ordering of a DAG places node u before v for every directed edge u→v. Only valid for Directed Acyclic Graphs (DAGs). Use case: package dependency resolution, course scheduling.

Kahn's Algorithm (BFS + In-Degree)

Pythonfrom collections import deque

def topological_sort(n: int, edges: list[list[int]]) -> list[int]:
    """Returns topological order, or [] if cycle detected."""
    graph = defaultdict(list)
    in_degree = [0] * n
    for u, v in edges:
        graph[u].append(v)
        in_degree[v] += 1

    queue = deque(node for node in range(n) if in_degree[node] == 0)
    order = []

    while queue:
        node = queue.popleft()
        order.append(node)
        for neighbour in graph[node]:
            in_degree[neighbour] -= 1
            if in_degree[neighbour] == 0:
                queue.append(neighbour)

    return order if len(order) == n else []  # [] means cycle exists

🔗 7 · Union-Find (Disjoint Set Union)

Union-Find answers connectivity queries in near-constant time. Operations: find(x) — which set does x belong to? union(x,y) — merge two sets.

With path compression + union by rank, both operations are O(α(n)) — effectively O(1).

Pythonclass UnionFind:
    def __init__(self, n: int):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x: int) -> int:
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])  # path compression
        return self.parent[x]

    def union(self, x: int, y: int) -> bool:
        px, py = self.find(x), self.find(y)
        if px == py:
            return False              # already connected
        if self.rank[px] < self.rank[py]:
            px, py = py, px
        self.parent[py] = px          # union by rank
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1
        return True

    def connected(self, x: int, y: int) -> bool:
        return self.find(x) == self.find(y)
When to use Union-Find vs DFS/BFS: Union-Find is ideal for offline connectivity queries (process all edges, then answer queries). DFS/BFS is better for online traversal when you need the actual path.
