⚡ Part A — Concept Quiz

Question 1

You need to find the SHORTEST path between two nodes in an unweighted graph. Which algorithm should you use?

  • DFS — goes deep, explores the shortest path naturally
  • BFS — explores nodes level by level, guaranteeing the shortest hop count
  • Union-Find — answers connectivity in O(α(n))
  • Topological Sort — orders nodes by dependency
BFS guarantees the shortest path in unweighted graphs because it visits nodes in order of increasing distance from the source. DFS may find a path, but not necessarily the shortest one.
Question 2

For a sparse graph (V nodes, E ≪ V²), which representation is more memory-efficient?

  • Adjacency list — stores only existing edges, O(V+E) space
  • Adjacency matrix — O(1) edge lookup justifies the space
  • Both are equivalent for sparse graphs
  • Edge list is always better than both
Adjacency list uses O(V+E) space and is ideal for sparse graphs. An adjacency matrix always uses O(V²) space regardless of edge density — wasteful when E ≪ V².
Question 3

Topological sort is ONLY valid for which type of graph?

  • Any undirected graph
  • Any directed graph
  • Directed Acyclic Graphs (DAGs) only
  • Weighted directed graphs only
DAGs only. If the graph has a cycle, no valid topological ordering exists (Kahn's algorithm detects this: the output length will be less than V). Course Schedule II (LeetCode #210) is exactly this problem.
Question 4

What does path compression do in Union-Find?

  • It sorts nodes alphabetically for faster lookup
  • It makes every node on a find() path point directly to the root, flattening the tree
  • It compresses the edge list to save memory
  • It merges two trees by always making the left tree the root
Path compression makes all nodes on the path from x to the root point directly to the root after a find() call. This dramatically flattens trees over time, giving amortized O(α(n)) per operation.
Question 5

In cycle detection for DIRECTED graphs using DFS, you track nodes as WHITE/GRAY/BLACK. What does finding a GRAY neighbour mean?

  • A back-edge to an ancestor in the current DFS path — a cycle exists
  • The neighbour has already been fully explored — safe to skip
  • The neighbour is in a different connected component
  • The graph is undirected, not directed
Back-edge = cycle. GRAY means the node is currently on the active DFS recursion stack. Encountering a GRAY neighbour means we've found a path back to an ancestor — a directed cycle. BLACK = fully done, safe to skip.

#200 · Number of Islands

Medium

Given a 2D grid of '1's (land) and '0's (water), count the number of islands. An island is formed by adjacent (horizontal/vertical) '1's surrounded by water.

DFS BFS Connected Components

When you find a '1', run DFS/BFS to mark the entire connected island as visited (sink to '0'). Count how many times you start a new DFS. Time: O(m×n).

#207 · Course Schedule

Medium

Given numCourses and a list of prerequisites [a, b] meaning "to take a you must first take b", determine if you can finish all courses.

Topological Sort Cycle Detection Kahn's Algorithm

Build a directed graph of prerequisites. If it has a cycle, you cannot finish all courses. Use Kahn's algorithm: if the topological order doesn't include all nodes, a cycle exists.

#133 · Clone Graph

Medium

Given a reference of a node in a connected undirected graph, return a deep copy of the graph. Each node contains a value and a list of its neighbours.

DFS BFS Hash Map

Use a dict {original_node: cloned_node} as your visited map. When you encounter a node, if it's already in the map return the clone; otherwise create a new node, add to map, then recursively clone all neighbours.

#547 · Number of Provinces

Medium

Given an n×n adjacency matrix isConnected where isConnected[i][j]=1 means city i and city j are directly connected, find the total number of provinces (connected components).

Union-Find DFS Connected Components

Either DFS/BFS on the adjacency matrix treating each city as a node, or use Union-Find: iterate all pairs (i,j) where isConnected[i][j]=1 and union them. Count remaining unique roots.

#994 · Rotting Oranges

Medium

Given a grid where 0=empty, 1=fresh orange, 2=rotten orange. Every minute, any fresh orange adjacent to a rotten one becomes rotten. Return the minimum minutes until no fresh orange remains, or -1 if impossible.

Multi-source BFS Grid Traversal

Multi-source BFS: start BFS from ALL rotten oranges simultaneously (enqueue all '2' cells at the start). Each BFS level = one minute. After BFS, if any '1' remains, return -1.

🤝 Part D — Peer Review Checklist

  • Visited set: Is the visited set (or mark) initialized before starting traversal to prevent infinite loops?
  • Add to visited before or at enqueue: For BFS, are nodes marked visited when enqueued (not when dequeued) to avoid duplicates in queue?
  • Disconnected graph: Does the solution iterate over all nodes (not just start from one) to handle disconnected components?
  • Topological sort cycle check: Does the solution verify len(order) == n after Kahn's algorithm to confirm no cycle exists?
  • Union-Find path compression: Is find() implemented recursively with parent[x] = find(parent[x]) assignment?
  • Complexity stated: Are both time O(V+E) and space O(V) complexities correctly identified and justified?
