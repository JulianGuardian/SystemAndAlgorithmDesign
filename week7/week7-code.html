Binary Trees & BST

Tree Traversals · Height · LCA · Diameter · BST Insert / Search / Validate

🎯 Learning Objectives

  • Implement and trace all three DFS traversal orders (in-order, pre-order, post-order) both recursively and iteratively.
  • Compute tree height and the diameter of a binary tree using a single DFS pass.
  • Find the Lowest Common Ancestor (LCA) for general binary trees and BSTs.
  • Insert, search, and validate a Binary Search Tree using the min/max bounds technique.

🌳 1 · Tree Fundamentals

The Node

Pythonclass TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val   = val
        self.left  = left
        self.right = right

🔄 2 · Traversals — In / Pre / Post-Order

Given a tree rooted at 4 with left subtree 2 (1, 3) and right subtree 6 (5, 7):

  • In-order (Left → Root → Right): 1 2 3 4 5 6 7 — gives sorted output for a BST
  • Pre-order (Root → Left → Right): 4 2 1 3 6 5 7 — useful for copying/serializing a tree
  • Post-order (Left → Right → Root): 1 3 2 5 7 6 4 — children before parent; used in deletion/evaluation

Recursive implementations

Pythondef inorder(root: TreeNode) -> list[int]:
    if not root:
        return []
    return inorder(root.left) + [root.val] + inorder(root.right)

def preorder(root: TreeNode) -> list[int]:
    if not root:
        return []
    return [root.val] + preorder(root.left) + preorder(root.right)

def postorder(root: TreeNode) -> list[int]:
    if not root:
        return []
    return postorder(root.left) + postorder(root.right) + [root.val]

Iterative in-order (stack-based)

Pythondef inorder_iterative(root: TreeNode) -> list[int]:
    result, stack = [], []
    curr = root
    while curr or stack:
        while curr:               # go as far left as possible
            stack.append(curr)
            curr = curr.left
        curr = stack.pop()        # leftmost unvisited
        result.append(curr.val)
        curr = curr.right         # try right subtree
    return result
Interview tip: Interviewers often ask for iterative traversal after you give the recursive solution. The pattern above — push left, pop, visit, go right — is the universal iterative in-order template.

📏 3 · Tree Height & Max Depth

LeetCode #104 asks: "Given a binary tree, return its maximum depth." Max depth = height + 1 (counting nodes, not edges).

Pythondef maxDepth(root: TreeNode) -> int:
    if not root:
        return 0                # base case: empty tree has depth 0
    left_d  = maxDepth(root.left)
    right_d = maxDepth(root.right)
    return 1 + max(left_d, right_d)  # add 1 for current node
Complexity: O(n) time — every node is visited exactly once. O(h) space on the call stack, where h is the tree height: O(log n) for balanced, O(n) worst case (skewed tree).

🔗 4 · Lowest Common Ancestor (LCA)

The LCA of nodes p and q is the deepest node that has both p and q as descendants (a node is a descendant of itself). LeetCode #236.

Key insight: Use post-order traversal. At each node, if the node itself is p or q → return it. If both subtrees return non-null → this node IS the LCA. If only one subtree returns non-null → bubble that up. 
Pythondef lowestCommonAncestor(root, p, q):
    if not root or root is p or root is q:
        return root              # base: found one of the targets
    left  = lowestCommonAncestor(root.left,  p, q)
    right = lowestCommonAncestor(root.right, p, q)
    if left and right:
        return root              # p in one subtree, q in the other
    return left or right        # one side found both (or neither)

📐 5 · Diameter of a Binary Tree

The diameter is the length (in edges) of the longest path between any two nodes. The path may or may not pass through the root. LeetCode #543.

Trick: Use a nonlocal variable to track the running max. For each node, the longest path through it is left_height + right_height. The recursive return value is the height (for the parent's calculation), while the side effect updates the diameter. 
Pythondef diameterOfBinaryTree(root: TreeNode) -> int:
    diameter = 0

    def height(node):
        nonlocal diameter
        if not node:
            return 0
        left_h  = height(node.left)
        right_h = height(node.right)
        diameter = max(diameter, left_h + right_h)  # path through this node
        return 1 + max(left_h, right_h)             # height for parent

    height(root)
    return diameter

🔍 6 · Binary Search Tree (BST)

A BST enforces the invariant: left subtree values < node < right subtree values at every node. This enables O(log n) search on balanced trees.

Insert

Pythondef insert(root: TreeNode, val: int) -> TreeNode:
    if not root:
        return TreeNode(val)
    if val < root.val:
        root.left  = insert(root.left,  val)
    else:
        root.right = insert(root.right, val)
    return root

Validate BST — min/max bounds

Pythondef isValidBST(root: TreeNode) -> bool:
    def check(node, lo, hi):
        if not node:
            return True
        if not (lo < node.val < hi):
            return False
        return (check(node.left,  lo,       node.val) and
                check(node.right, node.val, hi))

    return check(root, float('-inf'), float('inf'))

Search

Pythondef searchBST(root: TreeNode, val: int) -> TreeNode:
    if not root or root.val == val:
        return root
    if val < root.val:
        return searchBST(root.left,  val)
    return searchBST(root.right, val)
Common mistake: Checking only the immediate children to validate a BST. A node can violate the BST property with an ancestor, not just its direct parent. Always use the min/max bounds approach.
