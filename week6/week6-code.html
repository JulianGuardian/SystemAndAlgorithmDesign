📚 1 · Stack — Core Concept

Last In, First Out (LIFO). Think of a stack of plates — you add and remove from the top only. In Python, a regular list works perfectly as a stack using append() (push) and pop() (pop) — both O(1).

Python# Python list as stack — no import needed
stack = []
stack.append(1)    # push  → [1]
stack.append(2)    # push  → [1, 2]
stack.append(3)    # push  → [1, 2, 3]
top = stack[-1]    # peek  → 3  (no removal)
val = stack.pop()   # pop   → 3, stack is [1, 2]

# Explicit Stack class (often asked in interviews)
class Stack:
    def __init__(self):
        self._data = []

    def push(self, val) -> None:
        self._data.append(val)

    def pop(self):
        if self.is_empty():
            raise IndexError("pop from empty stack")
        return self._data.pop()

    def peek(self):
        return self._data[-1] if self._data else None

    def is_empty(self) -> bool:
        return len(self._data) == 0

🔐 2 · Pattern: Valid Parentheses (#20)

The stack is perfect for matching problems: push opening brackets, pop when a closing bracket is found, and verify the top matches.

Pythondef is_valid(s: str) -> bool:
    stack = []
    matching = {')': '(', ']': '[', '}': '{'}
    for ch in s:
        if ch in ('(', '[', '{'):
            stack.append(ch)      # push opening
        elif not stack or stack[-1] != matching[ch]:
            return False          # mismatch or empty stack
        else:
            stack.pop()           # matching bracket found
    return not stack            # valid iff stack is empty

# Time: O(n)  Space: O(n)

📈 3 · Pattern: Monotonic Stack

A monotonic stack maintains elements in increasing or decreasing order. It solves "find the next/previous greater/smaller element" problems in O(n) instead of O(n²).

Intuition: As you scan left-to-right, pop elements from the stack whenever the current element is a valid "answer" to the popped element's question. The element that caused the pop IS the answer. 
Python# Daily Temperatures #739 — next warmer day
# For each day, find how many days until a warmer temperature
def daily_temperatures(temperatures: list[int]) -> list[int]:
    n = len(temperatures)
    result = [0] * n
    stack = []  # stores indices, temperatures are decreasing in stack

    for i, temp in enumerate(temperatures):
        while stack and temperatures[stack[-1]] < temp:
            prev_idx = stack.pop()
            result[prev_idx] = i - prev_idx  # days waited
        stack.append(i)

    return result  # remaining in stack → 0 (no warmer day)

# Example: [73,74,75,71,69,72,76,73] → [1,1,4,2,1,1,0,0]
# Time: O(n) — each index pushed/popped at most once
# Space: O(n) — worst case stack holds all indices

Python# Next Greater Element — same pattern, applied to different problem
def next_greater_element(nums: list[int]) -> list[int]:
    result = [-1] * len(nums)
    stack = []  # decreasing monotonic stack
    for i, n in enumerate(nums):
        while stack and nums[stack[-1]] < n:
            result[stack.pop()] = n
        stack.append(i)
    return result

🚶 4 · Queue & Deque

First In, First Out (FIFO). Queues process elements in the order they arrive. In Python, use collections.deque — it supports O(1) append/popleft from both ends, unlike a list which is O(n) for popleft.

Pythonfrom collections import deque

# BFS Template — level-order traversal / shortest path
def bfs_level_order(root) -> list[list[int]]:
    if not root:
        return []
    result = []
    queue = deque([root])

    while queue:
        level_size = len(queue)    # snapshot: how many nodes at this level
        level = []
        for _ in range(level_size):
            node = queue.popleft()
            level.append(node.val)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        result.append(level)

    return result
# Time: O(n)  Space: O(n) — queue holds at most one full level

🪟 5 · Pattern: Sliding Window Maximum (#239)

Find the maximum in every window of size k as the window slides. Brute force is O(n·k). A monotonic deque solves it in O(n).

Pythonfrom collections import deque

def max_sliding_window(nums: list[int], k: int) -> list[int]:
    dq = deque()   # stores indices; values are decreasing
    result = []

    for i, n in enumerate(nums):
        # Remove indices outside the window
        while dq and dq[0] < i - k + 1:
            dq.popleft()

        # Remove indices whose values are smaller than current
        # (they can never be the max while current is in window)
        while dq and nums[dq[-1]] < n:
            dq.pop()

        dq.append(i)

        if i >= k - 1:           # window is full
            result.append(nums[dq[0]])  # front of deque = max

    return result
# Time: O(n) — each index added and removed at most once
