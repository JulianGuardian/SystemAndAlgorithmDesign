⚡ Part A — Big O Quick Quiz

Select an answer, then click Reveal to check your reasoning. Your score is tracked in the sticky bar above.

Question 1

What is the time complexity of the following snippet?

for i in range(n): for j in range(n): print(i, j)
  • O(n)
  • O(n²)
  • O(log n)
  • O(n log n)
Two nested loops each running n times → n × n = O(n²). Every element pair (i,j) is visited exactly once.
Question 2

A function calls itself recursively halving the input each time and does O(1) work per call. What is its time complexity?

  • O(n)
  • O(n²)
  • O(log n)
  • O(1)
Halving n repeatedly: n → n/2 → n/4 → ... → 1. This takes log₂(n) steps. Each step does O(1) work → total O(log n). This is the hallmark of binary search.
Question 3

Which Big O class grows the slowest?

  • O(log n)
  • O(n)
  • O(n log n)
  • O(√n)
Among the options: log n < √n < n < n log n. O(log n) grows the slowest. For n=1,000,000: log n ≈ 20, √n = 1000, n = 1,000,000.
Question 4

Simplify: O(3n² + 100n + 500). What is the tightest Big O?

  • O(n)
  • O(n²)
  • O(3n²)
  • O(n³)
Drop constants (3) and lower-order terms (100n, 500). The dominant term is n². Answer: O(n²).
Question 5

An algorithm creates a new list of size n inside a loop that runs n times. What is the space complexity?

  • O(1)
  • O(n)
  • O(n²)
  • O(log n)
Each of the n iterations allocates a list of size n. Total memory = n × n = O(n²). If those lists were discarded inside the loop body the answer would be O(n), but if they're accumulated (e.g. appended to an outer list) it's O(n²).

#704 · Binary Search

Easy

Given a sorted array of integers nums and a target, return the index of target or -1 if not found. You must write an O(log n) algorithm.

Key concepts: Binary Search O(log n)

Maintain lo and hi pointers. Compute mid = lo + (hi-lo)//2. Compare nums[mid] to target and move one pointer. Stop when lo > hi.

#167 · Two Sum II — Input Array Is Sorted

Medium

Given a 1-indexed sorted array, find two numbers that add up to a target and return their indices. Use O(1) extra space.

Key concepts: Two Pointers O(n)

Place lo=0, hi=len-1. If sum is too big, decrement hi (smaller right value). If too small, increment lo (bigger left value).

#3 · Longest Substring Without Repeating Characters

Medium

Given a string, find the length of the longest substring without repeating characters.

Key concepts: Sliding Window Hash Map O(n)

Use a dictionary to map each character to its last seen index. When you find a repeat, advance lo to last_seen[ch]+1 (only if that position is within the window).

#209 · Minimum Size Subarray Sum

Medium

Given an array of positive integers and a target sum, return the minimum length of a contiguous subarray whose sum is ≥ target. Return 0 if no such subarray exists.

Key concepts: Sliding Window (variable) O(n)

Expand hi adding to a running sum. When sum ≥ target, record the window length, then shrink from lo and keep shrinking as long as the condition holds. All positive numbers means shrinking always reduces the sum.

#153 · Find Minimum in Rotated Sorted Array (Bonus)

Medium

A sorted array was rotated at an unknown pivot. Find the minimum in O(log n) — do not use a linear scan.

Key concepts: Binary Search on answer space

Compare nums[mid] to nums[hi]. If nums[mid] > nums[hi], the minimum is in the right half. Otherwise it's in the left half (inclusive of mid).

🤝 Part C — Peer Review Checklist

After solving, swap code with a classmate. Use this checklist to review their solution. Both reviewers sign off before submitting.

  • Correctness: Does the solution pass the provided examples and edge cases (empty array, single element, all duplicates)?
  • Complexity stated: Did the author explicitly state time AND space complexity in a comment?
  • No brute force: For binary search problems, is there a nested loop that could be eliminated?
  • Off-by-one safe: Verify loop conditions (lo <= hi vs lo < hi) are correct and boundaries are handled.
  • Variable names: Are variables named clearly? (lo/hi, left/right, not a/b)
  • Overflow prevention: For binary search, is mid computed as lo + (hi-lo)//2?
  • One improvement suggestion: Write at least one concrete suggestion for improving the solution.
