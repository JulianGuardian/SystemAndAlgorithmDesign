➕ 1 · Prefix Sum

A prefix sum (a.k.a. cumulative sum) array allows answering range sum queries in O(1) after an O(n) build step. Instead of re-summing a subarray every time, precompute the total up to each index.

prefix[i] = prefix[i-1] + nums[i-1] (1-indexed, prefix[0]=0)
Sum from index l to r = prefix[r+1] − prefix[l] 
Pythondef build_prefix(nums: list[int]) -> list[int]:
    prefix = [0] * (len(nums) + 1)
    for i, v in enumerate(nums):
        prefix[i + 1] = prefix[i] + v
    return prefix   # O(n) time, O(n) space

def range_sum(prefix: list[int], l: int, r: int) -> int:
    return prefix[r + 1] - prefix[l]   # O(1) per query

# ── 2D prefix sum (rectangle query) ──
def build_2d_prefix(matrix: list[list[int]]) -> list[list[int]]:
    m, n = len(matrix), len(matrix[0])
    p = [[0] * (n + 1) for _ in range(m + 1)]
    for r in range(m):
        for c in range(n):
            p[r+1][c+1] = (matrix[r][c] + p[r][c+1]
                           + p[r+1][c] - p[r][c])
    return p   # inclusion-exclusion principle

🔲 2 · Matrix Traversal

Many interview problems reduce to exploring a 2D grid. Mastering the traversal patterns and their boundary conditions is essential.

Pattern 1 — Walk the matrix (all cells, row by row)

Pythondef walk_matrix(matrix: list[list[int]]) -> list[int]:
    result = []
    for row in matrix:
        for val in row:
            result.append(val)
    return result   # O(m×n) time, O(1) extra space

Pattern 2 — 4-directional BFS/DFS (flood fill, islands)

PythonDIRS = [(-1,0),(+1,0),(0,-1),(0,+1)]

def dfs(grid, r, c, visited):
    if (r, c) in visited: return
    visited.add((r, c))
    for dr, dc in DIRS:
        nr, nc = r + dr, c + dc
        if 0 <= nr < len(grid) and 0 <= nc < len(grid[0]):
            dfs(grid, nr, nc, visited)

Pattern 3 — Spiral traversal

Pythondef spiral_order(matrix: list[list[int]]) -> list[int]:
    result = []
    top, bottom = 0, len(matrix) - 1
    left, right  = 0, len(matrix[0]) - 1
    while top <= bottom and left <= right:
        for c in range(left, right + 1):   result.append(matrix[top][c])
        top += 1
        for r in range(top, bottom + 1):   result.append(matrix[r][right])
        right -= 1
        if top <= bottom:
            for c in range(right, left - 1, -1): result.append(matrix[bottom][c])
            bottom -= 1
        if left <= right:
            for r in range(bottom, top - 1, -1): result.append(matrix[r][left])
            left += 1
    return result   # O(m×n) time, O(1) extra space

🔤 3 · Anagrams & Frequency Maps

Two strings are anagrams if they contain the same characters with the same frequencies. A character frequency map captures this in O(n) and supports O(1) comparison.

Canonical key trick: Sort the string → anagrams share the same sorted key.
Better: Use a tuple of 26 counts as the key (avoids O(k log k) sort per string). 
Pythonfrom collections import defaultdict

def is_anagram(s: str, t: str) -> bool:
    """O(n) time, O(1) space (fixed 26-char alphabet)."""
    if len(s) != len(t): return False
    count = [0] * 26
    for a, b in zip(s, t):
        count[ord(a) - ord('a')] += 1
        count[ord(b) - ord('a')] -= 1
    return all(x == 0 for x in count)

def group_anagrams(strs: list[str]) -> list[list[str]]:
    """Group strings that are anagrams of each other. O(n·k) time."""
    groups: dict[tuple, list] = defaultdict(list)
    for s in strs:
        key = tuple(sorted(s))   # or tuple(count_array) for O(k) instead of O(k log k)
        groups[key].append(s)
    return list(groups.values())

# group_anagrams(["eat","tea","tan","ate","nat","bat"])
# → [["eat","tea","ate"], ["tan","nat"], ["bat"]]

🔍 4 · Substring Search

Sliding Window Approach: Find all anagram positions

Check every window of length len(p) in s using a frequency count that updates in O(1) per slide.

Pythondef find_anagrams(s: str, p: str) -> list[int]:
    """All start indices in s where an anagram of p begins. O(n) time."""
    need = len(p)
    if len(s) < need: return []
    p_count = [0] * 26
    w_count = [0] * 26
    for ch in p: p_count[ord(ch) - 97] += 1
    for ch in s[:need]: w_count[ord(ch) - 97] += 1
    result = [0] if p_count == w_count else []
    for i in range(need, len(s)):
        w_count[ord(s[i]) - 97] += 1         # add right
        w_count[ord(s[i - need]) - 97] -= 1  # drop left
        if p_count == w_count:
            result.append(i - need + 1)
    return result
