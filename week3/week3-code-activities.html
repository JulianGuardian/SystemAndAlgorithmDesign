⚡ Part A — Quick Quiz

Question 1

Given prefix = [0,3,4,8,9,14,23], what is the sum of elements at indices 2 to 4 (0-indexed)?

  • 9
  • 10
  • 14
  • 6
prefix[5] − prefix[2] = 14 − 4 = 10. Indices 2,3,4 hold values 4,1,5 which sum to 10.
Question 2

Are "listen" and "silent" anagrams?

  • Yes
  • No
Yes. Both contain exactly: e×1, i×1, l×1, n×1, s×1, t×1. Their character frequency maps are identical.
Question 3

What is the time complexity of building a prefix sum array of length n?

  • O(1)
  • O(n)
  • O(n²)
  • O(log n)
O(n) — one pass through the array to compute cumulative sums. Each query afterwards is O(1).
Question 4

How many cells does a spiral traversal of an m×n matrix visit?

  • m + n
  • m × n − 1
  • m × n
  • 2(m+n)−4
m × n — every cell is visited exactly once regardless of traversal order.
Question 5

When comparing two frequency-count arrays of length 26, what is the time complexity of the comparison?

  • O(1) — fixed alphabet size
  • O(n)
  • O(26 log 26)
  • O(n log n)
O(1) — comparing two arrays of constant length 26 is constant-time work, regardless of the input string length.

#303 · Range Sum Query – Immutable

Easy

Given an integer array, handle multiple range sum queries efficiently. Build a prefix sum once in the constructor; each query must be O(1).

Prefix Sum

Build self.prefix in __init__. In sumRange(l,r) return self.prefix[r+1] - self.prefix[l].

#49 · Group Anagrams

Medium

Given an array of strings, group the anagrams together. Each group may be returned in any order.

Hash Map Frequency Map

Use tuple(sorted(s)) as the dictionary key. All anagrams map to the same sorted key. Group under that key.

#54 · Spiral Matrix

Medium

Given an m×n matrix, return all elements in spiral order.

Matrix Traversal Boundary Shrink

Maintain four boundaries: top, bottom, left, right. After traversing each side, shrink that boundary inward and check if boundaries have crossed before the next side.

#438 · Find All Anagrams in a String

Medium

Given strings s and p, return all start indices of p's anagrams in s. The answer can be in any order.

Sliding Window Frequency Map

Fixed-size window of length len(p). Add the new right character, drop the leftmost character, compare frequency arrays in O(1) (array of length 26).

#560 · Subarray Sum Equals K (Bonus)

Medium

Given an integer array and an integer k, return the total number of subarrays whose sum equals k. Array may contain negatives.

Prefix Sum + Hash Map

If prefix[j] - prefix[i] == k, then subarray i..j-1 sums to k. Track prefix sum frequencies in a dictionary. For each prefix sum, check if prefix − k has been seen before.

🤝 Part D — Peer Review Checklist

  • Prefix array size: Is it length n+1 (not n) to allow the l=0 edge case?
  • Copy vs. reference: When building frequency maps, are string characters iterated (not list slices)?
  • Complexity stated: Separately stated for build phase and query phase?
  • Matrix bounds: Are out-of-bounds accesses prevented before indexing?
  • Window slide correctness: Correct order: add right → compare → drop left (or drop left → add right, depending on design)?
