⚡ Part A — Quick Quiz

Question 1

What is the average-case time complexity of inserting a key into a hash table?

  • O(1)
  • O(n)
  • O(log n)
  • O(n²)
O(1) average — hash function runs in O(k) where k=key length (treated as constant), then array index write is O(1). Worst case (all collisions) is O(n), but rare with a good hash function and load factor.
Question 2

Floyd's cycle detection uses two pointers. What happens if there is NO cycle?

  • They meet at the tail node
  • slow catches up to fast
  • fast reaches None (end of list)
  • They meet at the head
Without a cycle, fast advances two steps at a time and eventually reaches None. The while loop condition fast and fast.next exits, and we return False.
Question 3

Why do we use a dummy head node when merging two sorted linked lists?

  • To store the count of merged nodes
  • To avoid special-casing the first node assignment
  • To detect cycles in the merged list
  • To reduce memory usage
Avoiding edge cases. Without a dummy head, you need special logic to initialize the merged list's head. With a dummy, tail.next = smaller_node always works uniformly, and you return dummy.next at the end.
Question 4

What is the space complexity of reversing a linked list iteratively?

  • O(1)
  • O(n)
  • O(log n)
  • O(n²)
O(1) — the iterative approach only uses three pointers (prev, curr, nxt) regardless of list size. Contrast with the recursive approach which uses O(n) call stack.
Question 5

A hash table has 10 buckets and 8 entries. What is its load factor?

  • 10
  • 0.1
  • 0.8
  • 8
Load factor = entries / buckets = 8 / 10 = 0.8. This is close to the 0.75 threshold where most implementations trigger a resize to maintain O(1) performance.

💻 Part B — LeetCode Problem Set

#1 · Two Sum

Easy

Given an array and a target, return indices of the two numbers that add to target. Each input has exactly one solution. You may not use the same element twice.

Hash Map O(n)

Single pass: for each number, check if target - num is already in the dictionary. If yes, return indices. If no, store num → index.

#206 · Reverse Linked List

Easy

Reverse a singly linked list. Solve it both iteratively (O(1) space) and recursively (O(n) space), then compare.

Linked List Three-pointer iterative

Three variables: prev=None, curr=head. In each iteration: save nxt=curr.next, then curr.next=prev, then advance both. Return prev at the end.

#141 · Linked List Cycle

Easy

Given the head of a linked list, determine if the list has a cycle. Return true if there is a cycle, false otherwise. Use O(1) memory (no visited set).

Floyd's Algorithm O(1) space

Two pointers: slow moves 1 step, fast moves 2 steps. If they ever point to the same node, there is a cycle. If fast reaches None, no cycle.

#21 · Merge Two Sorted Lists

Easy

Merge two sorted linked lists and return the head of the merged list. The merged list should be made by splicing together the nodes of the first two lists.

Dummy Head O(n+m)

Create dummy = ListNode(0). Use a tail pointer. In the while loop, compare l1.val and l2.val, attach the smaller node to tail.next, advance tail and that list's pointer. After the loop, attach the remaining list.

#19 · Remove Nth Node From End of List (Bonus)

Medium

Given the head of a linked list, remove the nth node from the end and return the head. Do it in one pass.

Two Pointers One pass O(n)

Advance fast pointer n+1 steps ahead. Then move both slow and fast together until fast is None. slow.next is the node to remove — set slow.next = slow.next.next. Use a dummy head to handle removing the head node.

🤝 Part D — Peer Review Checklist

  • No visited set in cycle detection: Solution uses O(1) space (Floyd's), not a hash set.
  • Dummy head used: Merge solution avoids if/else for the first element by using a dummy head.
  • Edge cases covered: Empty list (None head), single node list, both lists empty.
  • Hash map cleanup: No unnecessary keys stored that inflate space beyond O(n).
  • Pointer safety: fast.next checked before fast.next.next to avoid NullPointerError.
  • Complexity fully stated for all solutions.
