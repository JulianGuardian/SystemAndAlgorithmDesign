🗂 1 · Hash Tables — How They Work

A hash table maps keys to values with average O(1) get/set. Under the hood: a hash function converts any key to an integer index; that index identifies a bucket in an array.

Collision Resolution Strategies

StrategyIdeaBest caseWorst case (all keys same bucket)
ChainingEach bucket holds a linked listO(1)O(n)
Open Addressing (linear probe)Find next empty slot in arrayO(1)O(n)
In practice: Python's dict uses open addressing with a pseudo-random probe sequence. Java's HashMap uses chaining. Both give amortized O(1) with a good load factor (typically kept below 0.75).

Frequency Map Pattern

Pythonfrom collections import Counter, defaultdict

# Pattern 1: count element frequencies
def first_unique_char(s: str) -> int:
    count = Counter(s)   # {'l':2, 'e':1, 't':1, 'r':1, 'd':1}
    for i, ch in enumerate(s):
        if count[ch] == 1:
            return i
    return -1   # O(n) time, O(1) space (at most 26 keys)

# Pattern 2: two-sum lookup table
def two_sum(nums: list[int], target: int) -> list[int]:
    seen = {}   # value → index
    for i, n in enumerate(nums):
        complement = target - n
        if complement in seen:
            return [seen[complement], i]
        seen[n] = i
    return []   # O(n) time, O(n) space

🔗 2 · Linked Lists — Core Operations

A linked list is a chain of nodes, each storing a value and a pointer to the next node. Unlike arrays, insertion/deletion at the head is O(1) — but random access is O(n).

Node Definition

Pythonclass ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

↩ 3 · Reverse a Linked List

Reverse the direction of all next pointers. Three-pointer technique: track prev, curr, and save next before overwriting.

Pythondef reverse_list(head: ListNode) -> ListNode:
    """Iterative. O(n) time, O(1) space."""
    prev = None
    curr = head
    while curr:
        nxt       = curr.next   # save
        curr.next = prev        # flip pointer
        prev      = curr        # advance prev
        curr      = nxt         # advance curr
    return prev   # prev is now the new head

🐢🐇 4 · Cycle Detection — Floyd's Algorithm

Floyd's tortoise and hare uses two pointers moving at different speeds. If there is a cycle, the fast pointer will eventually lap the slow pointer and they will meet.

Pythondef has_cycle(head: ListNode) -> bool:
    """Floyd's tortoise and hare. O(n) time, O(1) space."""
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            return True
    return False

def find_cycle_start(head: ListNode) -> ListNode:
    """Find the node where the cycle begins. Phase 1: detect. Phase 2: locate."""
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast: break
    else:
        return None
    # Phase 2: reset one pointer to head; advance both at speed 1
    slow = head
    while slow != fast:
        slow = slow.next
        fast = fast.next
    return slow   # cycle entry point

🔀 5 · Merge Two Sorted Linked Lists

Use a dummy head node to avoid special-casing the first element. Compare heads of both lists, attach the smaller one, advance that pointer.

Pythondef merge_two_sorted(l1: ListNode, l2: ListNode) -> ListNode:
    """O(n+m) time, O(1) space (no new nodes created)."""
    dummy = ListNode(0)
    tail = dummy
    while l1 and l2:
        if l1.val <= l2.val:
            tail.next = l1
            l1 = l1.next
        else:
            tail.next = l2
            l2 = l2.next
        tail = tail.next
    tail.next = l1 or l2   # attach remaining non-empty list
    return dummy.next        # skip the dummy head
